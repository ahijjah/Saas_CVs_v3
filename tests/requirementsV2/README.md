# Requirements-v2 editor tests

Synthetic fixtures and mocked APIs only; no live jobs, no network. The test tools are NOT project dependencies:

    npm install --no-save vitest@3 jsdom@26 @testing-library/react@16 @testing-library/dom @testing-library/user-event@14
    npx vitest run --config tests/requirementsV2/vitest.config.ts

Run it as `npm run test:requirements-v2` (the same command, from package.json). Running `npx vitest run` WITHOUT the config runs the files in a
plain Node environment without jsdom; the user-event and DOM tests then fail with `Cannot read properties of undefined (reading 'Symbol(Node prepared
with document state workarounds)')`. That is the invocation, not the tests: the same files pass with the config.

`parity.json` holds Equalize / Normalize vectors generated by the backend (`services/requirements_v2/weights.py`); `logic.test.ts`
asserts the TypeScript implementation gives identical results. `tests/` is excluded from `tsc --noEmit` (tsconfig) so a checkout
without the test tools still type-checks.
